# 2-DOF Robotic Arm

## 📌 Project Overview

This project focuses on the design and control of a **2-Degree-of-Freedom (2-DOF) robotic arm** developed for educational purposes.

The mechanical structure of the robotic arm was designed and modeled using **SolidWorks**. The robot will later be modeled and controlled using **MATLAB** to study its kinematics and motion.

## 🎓 Educational Objectives

The main purpose of this project is to understand the fundamental concepts of robotic manipulators, including:

* Degrees of freedom (DOF)
* Revolute joints
* Robotic arm kinematics
* Forward kinematics
* Inverse kinematics
* Workspace analysis
* Trajectory generation
* Robot motion control
* MATLAB-based robotic control

## 🛠️ Software Used

* **SolidWorks** – Mechanical design and 3D modeling
* **MATLAB** – Kinematic modeling, trajectory generation, and robot control
* **VS Code** – Project development and Git management
* **GitHub** – Version control and project documentation

## 📐 Robot Configuration

The robotic arm has **2 degrees of freedom**, provided by two rotational joints.

The two joints allow the end-effector to move within a two-dimensional workspace.

## 💻 MATLAB Control

MATLAB will be used to develop the mathematical and control model of the robotic arm.

Planned MATLAB implementation includes:

* Forward kinematics
* Inverse kinematics
* Joint-space analysis
* End-effector position calculation
* Trajectory planning
* Motion simulation
* Robot control

The MATLAB code will be added to this repository as the project develops.
